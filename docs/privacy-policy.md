# BoneCrawler Privacy Policy

_Last updated: June 5, 2026_

This Privacy Policy explains how BoneCrawler handles data in the current web and Java runtime versions of the game.

## Summary

BoneCrawler does not currently require user accounts, cloud saves, or direct personal information to play.

The current game stores a small amount of gameplay and settings data locally on the player’s device so the game can remember preferences and local progress-related values.

## Data Stored Locally

BoneCrawler may store the following data locally in the browser or packaged runtime:

- local scoreboard entries
- player name
- audio settings
- display or layout preferences
- other small runtime preferences needed for normal game behavior

This data is stored on the local device and is used to support gameplay, interface settings, and packaged runtime behavior.

## Data BoneCrawler Does Not Currently Collect

BoneCrawler does not currently require or directly collect:

- account registration data
- email addresses
- payment information
- cloud profile data
- direct analytics tied to a player identity

## Packaged Runtime Notes

The Windows Java Edition uses a local runtime container to launch and host the game on the same device.

This packaged runtime may store the same local gameplay/settings values listed above, including local scoreboard and settings data, but it does not currently provide a public online account or cloud sync system.

## Third-Party Platforms

If you download BoneCrawler from third-party platforms or services such as GitHub, itch.io, storefronts, hosting providers, or operating-system distribution channels, those platforms may collect their own technical, download, device, or account-related data under their own privacy policies.

BoneCrawler does not control the privacy practices of those external platforms.

## Children’s Privacy

BoneCrawler is not designed to collect personal information from children through direct account or profile systems.

## Changes to This Policy

This Privacy Policy may be updated as the game, launcher, editor toolkit, website, storefront presence, or online services change over time.

If BoneCrawler later adds analytics, cloud saves, accounts, payments, online features, or external user-data services, this policy should be updated to reflect those changes before release.
